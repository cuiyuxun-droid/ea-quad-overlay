# ea-quad-overlay
EA-Quad-Overlay L4 dataset secondary development tasks and documentation

## Dataset Layout

This repository defines the shared workspace for the EA-Quad-Overlay L4
dataset pipeline. All samples, feature files, annotations, manifests, scripts,
and reports should follow the directory and naming rules in
[`docs/file_structure.md`](docs/file_structure.md).

Core identifiers:

- Sample ID: `EAQ000001`
- Segment ID: `EAQ000001_seg001`
- Micro-expression event ID: `EAQ000001_seg001_micro001`

The unified source index template is available at
[`source_index/source_index_template.csv`](source_index/source_index_template.csv).
